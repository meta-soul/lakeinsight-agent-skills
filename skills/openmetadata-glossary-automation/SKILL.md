# OpenMetadata 术语自动治理

使用 MCP 将技术表结构转化为可审核的业务术语与资产关联。默认只生成预览，不直接写入元数据。

## MCP 选择与前置检查

1. 优先使用 `openmetadata-mcp-server` 查询或写入术语、表、字段和元数据。
2. 仅当 OpenMetadata 中缺少表结构时，使用 `lakeinsight-mcp-server` 或 `LakeSoul-Mcp` 执行只读 Schema 查询。不要执行 DDL、DML 或连接管理操作。
3. 不使用 `LakeInsight-Mcp` 的数据源、任务、审批、程序包或生产任务管理能力。
4. 每次开始前，先读取 MCP 客户端暴露的实际工具名、参数和权限。不得根据工具组名称猜测工具名或 JSON 参数。
5. MCP 返回 `401`、认证失败或 Token 过期时立即停止；提示用户刷新认证。不得索取、打印、保存或硬编码 Token、Cookie、Authorization Header。

## 工作模式

### 预览模式（默认）

除非用户明确输入“确认执行”或等价的逐项写入授权，否则只做以下操作：

1. 查询目标术语库、已有术语、表 FQN、字段、当前术语和标签。
2. 基于用户提供的表结构、数据字典、指标口径或只读 MCP 查询生成术语建议。
3. 搜索同义词、名称和层级，识别已有术语，禁止重复创建。
4. 输出“待创建术语、待更新项、待关联表/字段、冲突与待确认口径”的预览清单。

### 执行模式

仅在用户明确确认预览清单后执行：

1. 仅创建预览中确认的缺失术语；默认状态为 `Draft`。
2. 不覆盖已存在术语的名称、描述、Owner、Reviewer、同义词或关联关系，除非用户逐项确认。
3. 按表级和字段级映射关联术语；采用合并方式保留已有标签和术语。
4. 写入后重新读取实体，核对术语 FQN、字段名和关联结果。
5. 输出创建、跳过、关联成功、失败和待人工处理的清单。

不要自动批准术语、不要删除术语或资产关联、不要修改审批人、不要写入分类标签或访问控制策略，除非用户明确要求且逐项确认。

## 术语生成规则

1. 使用稳定的中文业务名称作为术语名称；英文缩写或字段名放到显示名称或同义词。
2. 描述至少包含定义；指标类术语还要包含统计对象、时间窗口、公式或排除规则。口径不明确时标记“待业务确认”，不要编造。
3. 优先复用已有术语。不得仅因父级不同就创建含义相同的 `SKU`、`订单金额`、`国家` 等重复术语。
4. 表级关联宽泛概念，例如订单表关联“订单”；字段级关联叶子概念，例如 `order_id` 关联“订单编号”。
5. 字段关联成功后，术语页可能只按父级表聚合展示；必须在表的数据模式/字段详情中复核具体字段绑定。
6. 仅将稳定业务概念纳入正式术语库。测试表、临时字段或调试信息优先使用表描述或测试标签，不创建正式业务术语。
7. 术语的 Owner 和 Reviewer 由用户提供或从目标术语库继承；没有明确信息时不臆测。

## 标准流程

### 1. 收集目标

确认或推断以下信息；缺失时先提问，不写入：

- 目标术语库的名称或 FQN；
- 目标表和字段，或可用于发现它们的关键字；
- 术语来源：数据字典、业务定义、指标口径、CSV 或用户描述；
- 是否只预览，还是已授权执行；
- 是否需要 Owner、Reviewer、标签或参考资料。

### 2. 读取与去重

使用只读工具获取目标术语库、候选表的精确 FQN 和字段结构。对每个候选术语按以下顺序检查：

1. 完全相同的术语 FQN；
2. 同一术语库中的同名术语；
3. 同义词或显示名称匹配；
4. 已绑定到候选字段的术语。

将结果标为“复用”“新增候选”或“需人工判定”；冲突时不创建。

### 3. 输出预览

使用以下格式输出，等待确认：

| 动作 | 术语/资产 | 目标位置 | 原因或口径 | 风险 |
|---|---|---|---|---|
| 复用 | 订单编号 | `orders.order_id` | 已存在且定义一致 | 无 |
| 新增候选 | 7日日均销量 | 销售与产出指标/销量 | 需确认统计时区与排除规则 | 中 |
| 关联 | 订单金额 | `dwd_orders.total_amount` | 字段级业务含义 | 无 |

预览还必须列出：预计新增数、预计更新数、预计关联数、不会执行的操作，以及所有待确认问题。

### 4. 执行与验证

收到明确确认后，使用已发现的真实 MCP 工具逐项执行。每个写操作后读取结果验证；若单项失败，停止该项并继续不相关的安全项。不得将失败项伪报为成功。

最后报告：

- 新建、复用、跳过和失败的术语；
- 已关联的表和字段；
- 因权限、审批状态、工具缺失或口径不清而未执行的事项；
- 需要用户在 OpenMetadata UI 中复核的字段级关联。

## 工具缺口处理

若 MCP 未提供字段级术语关联工具，或无法读取列级术语：

1. 不改用猜测性的 PATCH 路径；
2. 仅输出精确的手工关联清单，包括表 FQN、字段名、目标术语 FQN；
3. 说明缺少的 MCP 工具能力，并请求补充工具 Schema 后再更新本 Skill。
